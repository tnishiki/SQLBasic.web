# SQLBasic.web
学習用 SQL Web サービスプログラムです。

## プロジェクト構成

```
SQLBasic.web/
├── index.html        # サービス紹介ページ本体
├── css/
│   └── styles.css   # カラーテーマとレイアウトのスタイル定義
├── js/
│   └── app.js       # 動的な UI 制御とサンプルクエリデータ
└── README.md        # 本ドキュメント
```

## 画面設計の概要

### レイアウト
- **ヘッダー**: ブランドロゴ、主要ナビゲーション、テーマ切り替えボタンを配置。スクロール時も追従してコンテンツへすぐアクセスできます。
- **ヒーローセクション**: サービスの価値提案と主要 CTA（SQL ラボへの導線、学習ロードマップの確認）。
- **機能紹介カード**: ステップ学習・クエリ試行・学習ログの 3 つをカード形式で説明。
- **カリキュラムタイムライン**: 初級・中級・上級それぞれのゴール、学習トピックを動的に生成して表示。
- **SQL ラボ**: クエリテンプレートボタン、Monaco Editor ベースのコードエディタ、実行結果のプレビューで疑似体験が可能。
- **FAQ**: details 要素でよくある質問を折りたたみ形式で提示。

### スタイル
- Google Fonts の Noto Sans JP を採用し、読みやすさを重視したタイポグラフィ。
- `css/styles.css` にスタイルを集約し、カード・タイムラインなどの再利用しやすいコンポーネントクラスを用意。
- CSS カスタムプロパティでライト / ダークテーマを制御。グラデーション背景と半透明カードによる柔らかな UI。
- レスポンシブ対応として、640px 未満ではナビゲーションを折りたたみ、メニューボタンと `.is-open` クラスで展開。

## JavaScript の役割

`js/app.js` で以下の UI ロジックを提供します。

- **学習カリキュラムのレンダリング**: `lessons` 配列からタイムラインの要素を生成。
- **クエリテンプレートの挿入**: 初級・中級・上級のテンプレートをボタンで選択し、エディタへ反映。
- **疑似実行機能**: 入力された SQL を解析した体で、想定カラムや行数のメッセージを表示。
- **テーマ切替とナビゲーション**: テーマボタンでライト/ダークをトグルし、状態に応じて `aria-pressed` とボタンラベルを更新。メニューボタンは `aria-expanded` と `.is-open` クラスを同期させ、アクセシブルにナビゲーションを表示。

## 動作確認

ブラウザで `index.html` を開くだけで利用できます。特別なビルドや依存パッケージは不要です。
